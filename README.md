# 💫 About Me:
🚀 About Me<br>
Welcome to my GitHub! I'm **Caleb Broussard**.

I build local-first and voice-enabled AI tools — currently focused on desktop assistants that combine speech, local models, and practical tool use.

<br>

🏗️ **Currently Working On**<br><br>

**Lumin:** An early-stage local-first voice AI assistant with a 3D audio-reactive visualizer, Ollama model routing, file/document tools, and experimental MCP support.<br><br>

Still an active prototype. Reliability and cross-platform polish are ongoing work.

<br>

🧑‍🤝‍🧑 **Looking to Collaborate On**<br><br>

• Local / on-device AI agents and voice interfaces.<br>
• Open-source tools that improve accessibility or productivity.<br>
• Practical multimodal AI applications (not just demos).<br><br>

🤝 **Looking for Help With**<br><br>

• Real-time audio pipeline robustness (echo cancellation, turn-taking, latency).<br>
• Cross-platform packaging and install experience.<br>
• UI/UX patterns for voice-first desktop applications.<br>
• Testing and hardening experimental agent systems.<br><br>

🌱 **Currently Learning**<br><br>

• Stronger local multimodal architectures.<br>
• Real-time streaming and low-latency audio techniques.<br>
• Better agent design patterns (routing, tool use, memory).<br><br>

💬 **Ask Me About**<br><br>

• Building voice-controlled desktop applications.<br>
• Integrating local LLMs (Ollama) with tool use.<br>
• Python + web frontend hybrids for desktop AI tools.<br>
• Early-stage agent system design trade-offs.<br><br>

⚡ **Fun Fact**<br>

I once built a voice-controlled typing assistant so I could dictate code while eating pizza. 🍕
