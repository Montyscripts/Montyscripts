💫 About Me
Hi, I'm Caleb Broussard.
I build local-first and voice-enabled AI tools — currently focused on desktop assistants that combine speech, local models, and practical tool use.
🏗️ Currently Working On
Lumin — An early-stage local-first voice AI assistant with a 3D audio-reactive visualizer, Ollama model routing, file/document tools, and experimental MCP support.  
Still an active prototype. Reliability and cross-platform polish are ongoing work.
🧑‍🤝‍🧑 Looking to Collaborate On
Local / on-device AI agents and voice interfaces
Open-source tools that improve accessibility or productivity
Practical multimodal AI applications (not just demos)
🤝 Looking for Help With
Real-time audio pipeline robustness (echo cancellation, turn-taking, latency)
Cross-platform packaging and install experience
UI/UX patterns for voice-first desktop applications
Testing and hardening experimental agent systems
🌱 Currently Learning
Stronger local multimodal architectures
Real-time streaming and low-latency audio techniques
Better agent design patterns (routing, tool use, memory)
💬 Ask Me About
Building voice-controlled desktop applications
Integrating local LLMs (Ollama) with tool use
Python + web frontend hybrids for desktop AI tools
Early-stage agent system design trade-offs
⚡ Fun Fact
I once built a voice-controlled typing assistant so I could dictate code while eating pizza. 🍕
